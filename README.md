# 棋盘桌宠五子棋

双击桌宠下五子棋：局域网双人对战，五款动漫角色桌宠（视频动作全量），浏览器设置页改昵称/好友/战绩。

## 下载安装

到 [Releases](../../releases) 页面下载：

| 文件 | 说明 |
|---|---|
| `chessboard_desktop_pet_light_v*_setup.exe` | 精简安装包（~97MB，内含便携 Python 运行时，无需装环境） |
| `pets-v*` Release 里的角色包 | 每个角色 1.2~2.1GB，按需下载 |

安装：双击 exe 即装（免管理员权限），装完桌面出现「棋盘桌宠」。

- 安装包没有代码签名，第一次运行时点「**更多信息 → 仍要运行**」。
- 精简版安装后默认角色是 canvas 兜底形象，安装目录 pets/anims/ 下放入角色包（或解压 Release 角色包）后重启生效。
- 每个人的昵称/好友/战绩只存各自安装目录，升级重装互不影响。

## 角色包下载方式（二选一）

1. **在线下载（推荐）**：桌宠右键 → 设置 →「📦 角色包」，按需下载。
2. **手动**：到 Releases 的 `pets-vN` 标签下载对应角色 zip，解压到安装目录（zip 内已是 pets/anims/… 路径，解压即到位）。

## 从源码运行

```
py -3 gomoku.py        # 需要 tkinter + Pillow
```
